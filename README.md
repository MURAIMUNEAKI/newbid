# 入札AIエージェント

## 📖 概要
このプロジェクトは、政府・自治体の入札情報（主に「調達ポータル」等の公開情報）を自動で収集・整理し、閲覧しやすくするためのツールです。
Pythonによるスクレイピングバックエンドと、シンプルで視認性の高いWebフロントエンドを組み合わせており、ボタン一つで最新の入札情報を取得・更新することができます。

特に「デジタル」「観光」「教育」「農業」「建設」「サービス」「その他」という主要な7カテゴリに自動分類し、関連性の高い案件のみをピックアップするフィルタリング機能を備えています。

## ✨ 主な機能

1.  **自動収集 & スクリーニング**
    *   指定されたキーワード（例：「DX」「インバウンド」「研修」など）に基づいて、Web上の入札情報を検索します。
    *   取得した情報から、タイトルに関連キーワードが含まれているものだけを厳選して表示します。

2.  **カテゴリ自動分類**
    *   以下の7カテゴリに自動で振り分けを行います。
        *   **デジタル**: DX、システム開発、Web制作、ハードウェア調達など
        *   **観光**: インバウンド施策、観光プロモーション、旅行企画など
        *   **教育**: 学校ICT、研修業務、教材作成など
        *   **農業**: 農産物プロモーション、農業支援システムなど
        *   **工事**: 建築、土木、修繕工事など
        *   **サービス**: 施設管理、警備、清掃、業務委託など
        *   **その他**: 物品購入など

3.  **鮮度管理**
    *   過去60日以内に公示された案件のみを抽出し、古い情報は自動的に除外します。

4.  **リアルタイム更新**
    *   Web画面上の「始める」または更新ボタンを押すことで、その場でPythonスクリプトが動作し、最新情報を取得します（ローカルサーバー動作時）。

5.  **モダンなUIデザイン**
    *   見やすさを重視したカード型レイアウトを採用。
    *   機関名、日付、カテゴリが一目で分かります。

## 🛠️ 技術スタック
*   **Backend**: Python 3.x
    *   `Flask`: ローカルWebサーバーおよびAPIエンドポイントの提供
    *   `requests`, `BeautifulSoup4`: WebスクレイピングとHTML解析
*   **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
*   **Data Storage**: JSON (ローカルファイルベース)

## 🚀 インストールとセットアップ

### 前提条件
*   Windows 環境（推奨）
*   Python 3.x がインストールされていること

### 1. 依存ライブラリのインストール
以下のコマンドを実行して、必要なPythonライブラリをインストールしてください。

```bash
pip install requests beautifulsoup4 flask
```

### 2. アプリケーションの起動
フォルダ内にある `start_app.bat` をダブルクリックするか、コマンドプロンプトで以下を実行してください。

```bash
python server.py
```

### 3. ブラウザでのアクセス
サーバーが起動すると、自動的にブラウザが立ち上がり以下のURLにアクセスします。
*   URL: `http://localhost:5001`

もし自動で開かない場合は、ブラウザのアドレスバーに直接入力してください。

## 📂 ファイル構成
```
.
├── server.py        # Flask Webサーバー。APIリクエストを受け取りスクレイパーを起動します
├── fetch_bids.py    # スクレイピングのコアロジック。KKJ等のサイトから情報を取得・解析します
├── index.html       # メインのUI画面
├── style.css        # デザインスタイルシート
├── script.js        # フロントエンドのロジック（表示制御、API通信）
├── data.js          # 初回表示用のデータファイル（fetch_bids.pyにより自動生成）
├── data.json        # サーバー交換用のデータファイル（fetch_bids.pyにより自動生成）
└── start_app.bat    # 起動用バッチファイル
```

## ⚠️ 注意事項
*   **スクレイピングについて**: 対象サイトの負荷にならないよう、リクエスト間隔や取得件数には制限を設けて設計されています。コードを改変して大量のリクエストを送る行為は避けてください。
*   **データソース**: 現在の設定は `kkj.go.jp` (検索機能) を対象としています。サイトの構造変更により取得できなくなる可能性があります。

## 📝 入札カテゴリの詳細設定
`fetch_bids.py` 内の `CONFIG` 変数を編集することで、検索キーワードやフィルタリングルールをカスタマイズすることが可能です。

```python
    CONFIG = [
        {
            "id": "digital",
            "queries": [{"S": "デジタル"}, ...],
            "title_keywords": ["AI", "RPA", ...] # ここに追加することでヒット率を調整可能
        },
        ...
    ]
```
